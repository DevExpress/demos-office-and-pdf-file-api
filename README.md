# DevExpress Office & PDF File API: Demo Applications

[DevExpress Office & PDF File API](https://www.devexpress.com/products/net/office-file-api/) is a non-visual .NET library that allows you to generate, read, and modify PDF files and Microsoft Office documents (Word, Excel, PowerPoint)[^1].

[^1]: Office, Excel, Word, PowerPoint are trademarks or registered trademarks of Microsoft Corporation.

DevExpress Office & PDF File API includes the following libraries:

- [AI-powered Extensions](https://docs.devexpress.com/OfficeFileAPI/405645/ai-powered-extensions)
- [Word Processing Document API](https://www.devexpress.com/products/net/office-file-api/word/)
- [Spreadsheet Document API](https://www.devexpress.com/products/net/office-file-api/spreadsheet/)
- [Presentation Document API](https://www.devexpress.com/products/net/office-file-api/powerpoint-presentation-api/)
- [PDF Document API](https://www.devexpress.com/products/net/office-file-api/pdf/)
- OCR (text recognition in images and scanned PDF documents)

## What's Inside

This repository contains demo projects that use **DevExpress Office and PDF File API**.

* .NET Console Applications: [Office File API/CS/Demos.Office.Console](/Office%20File%20API/CS/Demos.Office.Console/README.md)
* Blazor Web Applications: [Office File API/CS/Demos.Office.Web](/Office%20File%20API/CS/Demos.Office.Web/README.md)

 Demo projects implement common document management scenarios:

* Convert a document to another format.
* Add or extract content.
* Recognize text in images and scanned PDF documents (OCR).
* Digitally sign or protect a document.
* Use Mail Merge for bulk document generation.
* Modify document properties.
* Populate interactive PDF forms.
* Split and merge documents.

## Run Demos Locally

1. Clone the current repository:

    HTTPS:
    ```
    git clone https://github.com/DevExpress/demos-office-and-pdf-file-api.git
    ```
    SSH:
    ```
    git clone git@github.com:DevExpress/demos-office-and-pdf-file-api.git
    ```

2. Open a solution file in Visual Studio:

    * _Office File API/CS/Demos.Office.Web/Demos.Office.Web.sln_
    * _Office File API/CS/Demos.Office.Console/Demos.Office.Console.slnx_

3. Run the application.
