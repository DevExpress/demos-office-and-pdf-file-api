# Word Find and Replace

This sample uses the **New DevExpress Word Processing Document API (WordDocument)** to find and replace text in a Word document.

- Input: `Documents/Sample.docx`.
- `Operation`: `Replace` (default). Set it to `Remove` to delete all matches instead.
- `SearchText`: `search text`.
- `ReplaceText`: `replacement text`.
- Search uses default `TextSearchOptions`.
- Output: `Output/Modified_Document.docx` (DOCX) beside the executable.
