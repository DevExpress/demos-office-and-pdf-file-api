# Word Metadata

This sample uses the **New DevExpress Word Processing Document API (WordDocument)** to read metadata from a Word document.

- Input: `Documents/Sample.docx`.
- `IncludeDocumentProperties`: `true`, so the sample reads core properties (title, author, subject, keywords, category, company, manager, created and last printed dates).
- `IncludeCustomProperties`: `true`, so the sample lists custom properties with their value types.
- Output: `Output/Document_Metadata.txt` beside the executable.
