# Word Document Statistics

This sample uses the **New DevExpress Word Processing Document API (WordDocument)** to collect content statistics from a Word document.

- Input: `Documents/Sample.docx`.
- `IncludeHeaderFooter`: `true`, so header and footer content is counted.
- `IncludeTextBoxes`: `true`, so text box content is counted.
- The report lists sections, paragraphs, words, characters, tables, images/shapes, hyperlinks, bookmarks, and comments.
- Output: `Output/Document_Statistics.txt` beside the executable.
