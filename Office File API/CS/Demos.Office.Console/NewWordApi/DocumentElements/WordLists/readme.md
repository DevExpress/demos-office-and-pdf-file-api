# Word Lists (New Word API)

This sample uses the new DevExpress Word Processing Document API (`WordDocument`) to generate a bulleted list in a new document.

The sample applies the following predefined list settings:

- Number of items: 5
- Bullet character: `●`
- Indent size: 0.5 inch
- Hanging indent: 0.25 inch
- Space before and after: 0 points

The sample writes `Output/List_Result.docx` next to the executable.
