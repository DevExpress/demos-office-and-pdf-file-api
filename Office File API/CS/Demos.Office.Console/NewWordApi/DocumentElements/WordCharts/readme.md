# Word Charts (New Word API)

This sample uses the new DevExpress Word Processing Document API (`WordDocument`) to generate a chart in a new document. The sample creates a combo chart: a bar series shows units sold and a line series on the secondary axis shows total transactions.

The sample applies the following predefined chart settings:

- Show trendline: `true`
- Show data labels: `true`
- Show axis titles: `true`
- Show grid lines: `true`
- Show legend: `true`
- Legend position: `Right`

The sample writes `Output/Chart_Document.docx` next to the executable.
