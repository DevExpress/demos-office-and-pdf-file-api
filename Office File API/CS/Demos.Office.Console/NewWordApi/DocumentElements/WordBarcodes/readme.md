# Word Barcodes (New Word API)

This sample uses the new DevExpress Word Processing Document API (`WordDocument`) to generate a barcode in a new document.

The sample creates a Code128 barcode with the value `123456789012` and inserts it as an inline picture. The `BarcodeType` constant also accepts `QRCode` and `DataBar`.

The sample writes `Output/Bracode_Document.docx` next to the executable.
