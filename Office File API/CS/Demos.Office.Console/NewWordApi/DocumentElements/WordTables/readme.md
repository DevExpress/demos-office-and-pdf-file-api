# Word Tables (New Word API)

This sample uses the new DevExpress Word Processing Document API (`WordDocument`) to generate a table in a new document.

The sample applies the following predefined table settings:

- Rows and columns: 5 x 4
- Size mode: AutoFit to window (fixed column width setting: 1.5 inches)
- Border type: all borders
- Border style: single line, `#000000`, 1 point
- Text wrapping: none (horizontal and vertical position: 0 inches)
- Header row and sample data: included

The sample writes `Output/Table_Result.docx` next to the executable.
