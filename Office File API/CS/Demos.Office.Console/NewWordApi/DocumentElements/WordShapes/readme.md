# Word Shapes (New Word API)

This sample uses the new DevExpress Word Processing Document API (`WordDocument`) to insert a picture shape in a new document.

The sample reads `Documents/Photo1.jpeg` and inserts it as an inline picture with the following predefined settings:

- Image scale: 1
- Lock aspect ratio: `false`
- Outline color: `#9E67FF`
- Outline width: 1 point

The sample writes `Output/Shape_Document.docx` next to the executable.
