This module uses the **DevExpress OCR engine (`OcrEngine`)** to recognize text only in a selected area of a PDF page instead of processing the entire document. The sample document is a scanned report that contains a header, body, and footer.

Select the page region (**Header**, **Body**, or **Footer**) and use the **Recognize and export to...** drop-down button to select the output format (**PDF**, **TXT**, or **JSON**) and download the result. The OCR engine processes only the selected area. In the PDF output, only the selected area has the invisible text layer.
