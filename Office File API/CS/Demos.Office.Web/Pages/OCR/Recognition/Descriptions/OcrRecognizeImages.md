This module uses the **DevExpress OCR engine (`OcrEngine`)** to recognize text in images (PNG, JPEG, BMP, TIFF). You can process the predefined sample image (a scanned letter) or upload your own image.

Use the **Detect page orientation** option to automatically detect and correct the image rotation before recognition. Use the **Recognize and export to...** drop-down button to select the output format and download the result:

* **PDF** - a searchable PDF document that contains the original image and an invisible layer with the recognized text.
* **TXT** - recognized text as a plain text file.
* **JSON** - recognized text fragments with words, confidence values, and bounds (in image pixels).
