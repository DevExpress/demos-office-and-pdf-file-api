This demo uses the **New DevExpress Spreadsheet Document API (Workbook)** to analyze Excel workbook statistics. You can process the predefined sample file or supply your own document. To do the latter, select **Upload a File** in the file selection drop-down menu.

Select **Skip Hidden Worksheets** to exclude hidden worksheets from the analysis. Collected statistics include worksheet and chart sheet count, used cell count, and the number of tables, charts, images, and shapes in each worksheet.

Click **Analyze Workbook** to process the document and download the statistics report.
