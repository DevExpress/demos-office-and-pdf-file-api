This demo uses the **New DevExpress Spreadsheet Document API (Workbook)** to add, remove, or duplicate worksheets in Excel documents. You can process the predefined sample file or supply your own document. To do the latter, select **Upload a File** in the file selection drop-down menu.

Select the operation type and related parameters. Use the **Process and Save as...** dropdown button to select the output format, run the selected operation, and download the result.
