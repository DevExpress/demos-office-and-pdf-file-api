This demo uses the **New DevExpress Spreadsheet Document API (Workbook)** to add shapes to an Excel document. You can insert a picture, a textbox, a figure, or a group of figures and anchor them to worksheet cells or position them at absolute coordinates.

Demo settings allow you to specify shape type, content, and appearance.

Use the **Generate Shapes and Save as ...** dropdown button to select the output format, generate shapes with selected settings, and download the result.
