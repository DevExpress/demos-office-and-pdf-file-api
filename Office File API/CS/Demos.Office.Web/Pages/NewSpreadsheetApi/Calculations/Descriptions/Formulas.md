This demo uses the **New DevExpress Spreadsheet Document API (Workbook)** to create Excel documents with various formula types.

Select the formula type from the drop-down menu. Available formula types demonstrate different calculation capabilities and data reference methods. The demo calculates formulas on demand before the document is saved.

Use the **Create Document and Save as...** dropdown button to select the output format, generate a document with the selected formula type, and download the result.
