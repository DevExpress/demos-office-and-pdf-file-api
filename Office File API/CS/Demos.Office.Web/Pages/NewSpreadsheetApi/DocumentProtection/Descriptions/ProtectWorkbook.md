This demo uses the **New DevExpress Spreadsheet Document API (Workbook)** to password-protect a workbook (the password grants access to workbook modification operations). You can process the sample file or supply your own document. To do the latter, select **Upload a File** in the file selection drop-down.

Specify the protection password. Change settings in the **Protection Settings** panel, if required. Use the **Protect and Save as...** dropdown button to select the output format, protect the workbook, and download the result.
