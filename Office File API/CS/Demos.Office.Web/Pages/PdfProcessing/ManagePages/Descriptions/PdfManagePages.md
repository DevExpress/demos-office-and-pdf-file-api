This demo uses the **DevExpress PDF Document API ([PdfDocumentProcessor](https://docs.devexpress.com/OfficeFileAPI/16491/pdf-document-api))** to manage PDF pages. You can process the predefined sample file or supply your own document. To do the latter, select **Upload a File** in the file selection drop-down menu.

Select the required action and specify corresponding settings. Use the **Process PDF** button to update the document and download the result.
