This module uses the **DevExpress PDF Document API ([PdfDocumentProcessor](https://docs.devexpress.com/OfficeFileAPI/16491/pdf-document-api))** to manage PDF bookmarks. You can process the predefined sample file or supply your own document. To do the latter, select **Upload a File** in the file selection drop-down menu.

Select the operation type from the drop-down menu: create or remove bookmarks in the PDF document. Once you select the action, the demo processes the document and downloads the result.
