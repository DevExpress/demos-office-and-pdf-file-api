This module uses the **DevExpress Presentation API** to inspect and sanitize PowerPoint presentations (remove sensitive or hidden content). You can process the predefined sample file or supply your own presentation. To do the latter, select **Upload a File** in the file selection drop-down menu.

Select hidden content to remove in the **Remove Hidden Content** section (Slides, Shapes). Select sensitive content to remove in the **Remove Sensitive Content** section (ActiveX Content, Comments, Custom XML Parts, Embedded Chart Data, Macros, Metadata, Notes, OLE Objects).

Use available buttons to either produce a log on sensitive/hidden content or sanitize the presentation and download the result.
