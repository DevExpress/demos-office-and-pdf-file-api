This module uses the **DevExpress Presentation API** to securely load PowerPoint presentations with protection against potentially harmful content. You can process the predefined sample file or supply your own presentation. To do the latter, select **Upload a File** in the file selection drop-down menu.

Configure security constraints in the **Security Settings** section: set limits for the number of slides and shapes per slide. In the **Content Settings** section, select content types to remove (ActiveX Content, Custom XML Parts, Embedded Chart Data, Macros, OLE Objects, Restricted Links).

Use the **Convert Presentation to** dropdown button to select the output format, process the presentation, and download the result.
