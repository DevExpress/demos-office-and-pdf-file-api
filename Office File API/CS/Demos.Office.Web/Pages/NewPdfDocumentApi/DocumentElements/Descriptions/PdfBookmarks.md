This module uses the **New DevExpress PDF Document API (PdfDocument)** to manage PDF bookmarks. You can process the predefined sample file or supply your own document. To do the latter, select **Upload a File** in the file selection drop-down menu.

The demo either creates bookmarks on each page or clears all bookmarks. Select the operation type from the drop-down menu (add or remove bookmarks). Press the button to process the document and download the result.
