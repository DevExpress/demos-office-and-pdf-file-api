This module uses the **New DevExpress PDF Document API ([PdfDocument](https://docs.devexpress.com/OfficeFileAPI/405907/pdf-document-api-new))** to convert PDF files to PDF/A format. You can process the sample file or supply your own document. To do the latter, select **Upload a File** from the file selection drop-down menu.

Use the **Convert to...** dropdown button to select the conformance level (PDF/A-1b, PDF/A-2b, or PDF/A-3b), convert the document, and download the result. The **Download Conversion Report** button saves the conversion status and a list of detected issues.
