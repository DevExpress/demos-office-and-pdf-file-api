This module uses the **DevExpress Spreadsheet API** to analyze Excel workbook statistics. You can process the predefined sample file or supply your own document. To do the latter, select **Upload a File** in the file selection drop-down menu.

Select **Skip Hidden Worksheets** to exclude hidden worksheets from the analysis. Collected statistics include worksheet count, cell count, formula count, and other workbook information.

Click **Analyze Workbook** to process the document and download the statistics report.
