This module uses the **DevExpress Spreadsheet API** to clear cell data from an Excel document. You can process the predefined sample file or supply your own document. To do the latter, select **Upload a File** in the file selection drop-down menu.

Select whether you want to remove all content or specific content/attribute types (cell content, formatting, hyperlinks, comments).

Use the **Process and Save as XLSX** dropdown button to select the output format, run the operation, and download the result.
